นโยบายความเป็นส่วนตัว AniiGuide

AniiGuide เก็บข้อมูลอะไร เก็บไว้ที่ไหน ใช้บริการภายนอกอะไรบ้าง และขอลบข้อมูลได้อย่างไร

เปิดหน้านี้ในคู่มือ

AniiGuide (aniiguide.trade) เป็นเว็บคู่มือเกม Aniimo ภาษาไทยที่แฟนเกมทำ ไม่เกี่ยวข้องกับผู้พัฒนาเกม หน้านี้บอกว่าเว็บเก็บข้อมูลอะไร เก็บไว้ที่ไหน และใช้ทำอะไร

ไม่ต้องสมัครสมาชิก

ใช้ได้ทุกฟีเจอร์โดยไม่ต้องสมัครหรือล็อกอิน เว็บไม่ขอชื่อ อีเมล หรือเบอร์โทร

ข้อมูลที่เก็บไว้ในเครื่องของคุณเท่านั้น

ทีมที่จัด บิลด์ เช็กลิสต์ Aniimo ที่สะสม ประวัติที่เปิดดู ธีม และภาษา เก็บใน localStorage ของเบราว์เซอร์ ไม่ได้ส่งมาที่เว็บ ลบได้ทุกเมื่อด้วยการล้างข้อมูลเว็บไซต์ในเบราว์เซอร์

สถิติการใช้งาน

เพื่อรู้ว่าหน้าไหนมีคนใช้และควรปรับอะไร เว็บส่งข้อมูลต่อไปนี้ไปเก็บที่ Supabase: หน้าที่เปิด, Aniimo หรือไอเท็มที่เปิดดู, คำที่ค้นหาในเว็บ, รหัสสุ่มของเบราว์เซอร์ (ไม่ผูกกับตัวตน), รหัสสุ่มของรอบการเข้าเว็บ, ระยะเวลาที่ใช้งาน, ประเภทอุปกรณ์ (มือถือ แท็บเล็ต คอม), ภาษาของเบราว์เซอร์ และเขตเวลา เว็บไม่ได้เก็บชื่อ อีเมล หรือที่อยู่ IP ในฐานข้อมูลนี้ และไม่ใช้คุกกี้ติดตาม

สิ่งที่คุณส่งเอง

  • ส่งคำแนะนำ: ข้อความ ช่องทางติดต่อ (ถ้าใส่) และหน้าที่เปิดอยู่ตอนส่ง
  • โหวต Tier List: ตัวที่โหวต พร้อมรหัสสุ่มของเบราว์เซอร์เพื่อกันโหวตซ้ำ
  • รหัสซิงก์ข้ามเครื่อง: ถ้าเปิดใช้ ข้อมูลเช็กลิสต์และทีมจะถูกเก็บไว้กับรหัสซิงก์ที่คุณตั้ง ใครรู้รหัสก็โหลดข้อมูลนั้นได้ จึงไม่ควรใช้รหัสที่เดาง่าย

บริการภายนอกที่เว็บใช้

  • GitHub Pages และ Cloudflare ให้บริการเว็บและป้องกันการโจมตี อาจบันทึกที่อยู่ IP และข้อมูลเบราว์เซอร์ในบันทึกของระบบตามนโยบายของผู้ให้บริการ
  • Cloudflare R2 เก็บไฟล์โมเดล 3D
  • Google Fonts ให้บริการฟอนต์
  • YouTube (โหมดไม่ใช้คุกกี้) เมื่อกดเล่นคลิปในหน้าข่าว
  • Supabase เก็บสถิติ คำแนะนำ โหวต และข้อมูลซิงก์

ลิงก์ที่พาออกไปเว็บอื่น เช่น AniiDex หรือเว็บทางการของเกม ใช้นโยบายของเว็บนั้น

โฆษณา

ตอนนี้เว็บยังไม่มีโฆษณา ถ้าจะมีในอนาคต เช่น Google AdSense จะอัปเดตหน้านี้ก่อน และจะบอกว่าผู้ให้บริการโฆษณาใช้คุกกี้อย่างไร

ขอดูหรือลบข้อมูล

ส่งข้อความผ่านหน้า ส่งคำแนะนำ พร้อมช่องทางติดต่อกลับ ข้อมูลสถิติไม่ได้ผูกกับตัวตน จึงลบได้เมื่อแจ้งรหัสสุ่มของเบราว์เซอร์มาด้วย (ดูได้ด้านล่าง)

เงื่อนไขการใช้งาน

  • เว็บนี้เป็นแฟนเมด ไม่เกี่ยวข้องกับผู้พัฒนาเกม ชื่อ ภาพ และโมเดลของ Aniimo เป็นลิขสิทธิ์ของเจ้าของเกม
  • ข้อมูลรวบรวมจากในเกม ประกาศทางการ และ AniiDex (ได้รับอนุญาต) อาจคลาดเคลื่อนหรือเปลี่ยนตามอัปเดตของเกม
  • ห้ามนำเนื้อหาที่เขียนขึ้นสำหรับเว็บนี้ไปเผยแพร่ซ้ำเชิงพาณิชย์โดยไม่ได้รับอนุญาต แชร์ลิงก์ได้เสมอ
  • ติดต่อหรือแจ้งข้อมูลผิดได้ที่หน้า ส่งคำแนะนำ

ANIIGUIDE

คำถามที่พบบ่อยเกี่ยวกับ Aniimo (ภาษาไทย)

Aniimo เล่นฟรีไหม เล่นบนอะไรได้บ้าง คนไทยควรเลือกเซิร์ฟเวอร์ไหน ข้อมูลข้ามเครื่องได้ไหม และวิธีแก้ปัญหาที่เจอบ่อย

เปิดหน้านี้ในคู่มือ

Aniimo เล่นฟรีไหม เป็นเกมกาชาหรือเปล่า

เล่นฟรี และทีมพัฒนายืนยันว่าไม่ใช่เกมกาชา Aniimo ได้จากการจับในโลกเกม ไม่ได้สุ่มจากตู้ มีของขายเป็นชุดแต่งตัว Monthly Pass และ Companion Pass

เล่นได้บนอะไรบ้าง

PC (Steam, Epic, launcher ทางการ), PS5, Xbox Series X|S, iOS และ Android และเล่นผ่าน NVIDIA GeForce NOW ได้ด้วย

ข้อมูลข้ามเครื่องได้ไหม

ได้ ถ้าอยู่เซิร์ฟเวอร์เดียวกัน ความคืบหน้าใช้ร่วมกันทุกแพลตฟอร์ม แต่ข้อมูลแต่ละเซิร์ฟเวอร์แยกกัน ย้ายข้ามเซิร์ฟเวอร์ไม่ได้

คนไทยควรเลือกเซิร์ฟเวอร์ไหน

Aniimo-Apac (เอเชียแปซิฟิก, UTC+8) ใกล้ที่สุดและเป็นเซิร์ฟเวอร์ที่เว็บนี้ใช้อ้างอิงเวลา รีเซ็ตรายวัน 04:00 เวลาเซิร์ฟเวอร์ = 03:00 น. เวลาไทย

ข้อมูลช่วงทดสอบ (เบต้า) ยังอยู่ไหม

ไม่อยู่ ข้อมูลช่วงทดสอบถูกลบ แต่ถ้ามีสิทธิ์รับเงินคืนหรือรางวัลทดสอบ ให้ล็อกอินบัญชีเดิมที่หน้า Check Test Rewards บนเว็บทางการ

เคยใช้บัญชี Steam ตอนทดสอบ แต่ตอนนี้ใช้อีเมล รางวัลทดสอบย้ายได้ไหม

ได้ ผูกบัญชี Steam กับ Aniimo Pass ที่ใช้อีเมล ระบบจะให้ผูกตอนเข้าผ่าน Steam ครั้งแรก หรือผูกภายหลังในหน้า Email Link ในเกม

เข้าเกมแล้วจอดำ ทำยังไง

อัปเดตไดรเวอร์การ์ดจอ ลองสลับ DX11 กับ DX12 และปิด DLSS กับ Frame Generation ที่หน้าล็อกอิน

จอเป็นสีแดง

แก้แล้วในแพตช์ 18 ก.ย. ถ้ายังเจอ ให้ตั้งกราฟิกเป็น Performance Mode ชั่วคราว

จอยบน Steam ใช้ไม่ได้

คลังเกม Steam → Aniimo → Manage → Properties → Controller → เลือก Disable Steam Input แล้วเปิดเกมใหม่

มีคนบอกให้กดลิงก์รับรางวัลหรือสแกน QR เชื่อได้ไหม

ไม่ได้ ของรางวัลทั้งหมดส่งผ่านอีเวนต์และจดหมายในเกมเท่านั้น ทีมงานไม่ขอรหัสยืนยันหรือเงินโอน ห้ามให้รหัสผ่านใครเด็ดขาด

แจ้งปัญหาหรือติดต่อทีมงานได้ที่ไหน

ในเกม: เมนู → Support หรือกด F10 · อีเมล support_en@aniimo.com · Discord ทางการ discord.com/invite/aniimo

แลกโค้ดของขวัญที่ไหน

Settings → Account → Gift Code Redemption พิมพ์ตัวพิมพ์เล็ก-ใหญ่ให้ตรง ดูโค้ดที่ยังใช้ได้ในหน้าโค้ดแลกของของเว็บนี้

จะได้ Irisalis ยังไง

ช่วง 25 ก.ย. – 10 ธ.ค. เก็บ Iris Petal สร้าง Legendary Aniipod: Irisalis แล้วเข้า Rift Space สู้ตามเนื้อเรื่องและจับ ต้องมียศ Student I และพบได้ครั้งเดียว

เว็บนี้เป็นของทางการไหม

# AniiGuide — คู่มือเกม Aniimo ภาษาไทย

เว็บ: https://kittisakaicowork-pixel.github.io/aniimo-field-guide/

เว็บแอปคู่มือเกม Aniimo ภาษาไทย (แฟนเมด ไม่เกี่ยวข้องกับ Pawprint Studio)

- รายชื่อ Aniimo ทุกตัวที่เปิดในเกมแล้ว พร้อมค่าสถานะ สายวิวัฒนาการ เงื่อนไขวิวัฒนาการ จุดเกิด งานใน Homeland และไอเท็มแนะนำ
- สกิล 419 สกิล พร้อมสีธาตุ และคำอธิบายภาษาไทย (สลับเป็นต้นฉบับภาษาอังกฤษได้)
- ร่างพิเศษ 123 ร่าง และร่างเปล่งประกาย (Sparkling) 12 แบบต่อร่าง
- จัดทีม Combo พร้อมวิเคราะห์ และแชร์ทีมผ่านลิงก์ได้
- เช็กลิสต์สะสม เปรียบเทียบ Aniimo บอส Alpha/Omega 21 ตัว และภูมิภาค 14 แห่ง
- คู่มือมือใหม่ (ตัวเลือกที่ย้อนไม่ได้, เช็กลิสต์ช่วงแรก, ควรทำ/ไม่ควรทำ, ห้ามพลาด) และแนวทางพัฒนา Aniimo และบัญชี
- อีเวนต์พร้อมกติกาและตาราง และไอเท็มสำคัญ 91 ชิ้นพร้อมวิธีหา
- แผนที่ Idyll แบบโต้ตอบ หมุด 4,334 จุด (หีบ ไข่ Aniipod วัตถุดิบ บอส Alpha/Omega ด่าน Pathfinder ฯลฯ) พร้อมขอบเขต 14 ภูมิภาค
- ตารางธาตุ Tier List และโค้ดแลกของ
- หน้าเตรียมตัว Whisperwake Isles (เปิด 29 ต.ค. 2026) นับถอยหลัง Aniimo ใหม่ 10 ตัว และธาตุที่ควรเตรียม
- คู่มือ Holo-Battle Interlink, Operation: Egg Heist โหมด Chaos และการเล่นบนมือถือ/ข้ามแพลตฟอร์ม
- หน้าล่าไข่ (ไข่ 141 จุดบน Idyll แยกชนิดและภูมิภาค) และหน้า Operation: Egg Heist พร้อมแผนที่เกาะ Lost Isles และห้อง Lost Sanctum ทุกระดับความยาก
- เช็กลิสต์รายวัน/รายสัปดาห์ (รีเซ็ตเอง) · Held Item และ Rune · งานใน Homeland · ของกินและบัฟ · ชุดแต่งตัว · อุปกรณ์และชิป Egg Heist · ชนิดไข่ทั้งหมด · ปุ่มควบคุมและการตั้งค่า
- ซิงก์เช็กลิสต์ข้ามเครื่องด้วยรหัสซิงก์ · แจ้งของใหม่ตั้งแต่ครั้งก่อน · เพิ่มอีเวนต์ลงปฏิทิน · ปุ่มแชร์ Aniimo
- หน้าแยกสำหรับค้นหาและแชร์: Aniimo ทุกตัว (`a/<slug>/`) ข่าว และหัวข้อหลัก (`p/`) พร้อม `sitemap.xml`

## เปิดใช้งานในเครื่อง

เปิดผ่านเซิร์ฟเวอร์ในเครื่อง จะติดตั้งเป็นแอปและใช้งานออฟไลน์ได้

```bash
python3 -m http.server 8765
```

แล้วเปิด `http://localhost:8765` ส่วนเวอร์ชันเต็มให้รันคำสั่งเดียวกันในโฟลเดอร์ `dist-full`

## อัปเดตข้อมูลเมื่อเกมอัปเดต

```bash
python3 tools/scrape.py --refresh   # ดาวน์โหลดหน้าใหม่ทั้งหมด แล้วบอกว่ามีโค้ดใหม่ไหม
python3 tools/build.py              # สร้างเวอร์ชันเว็บ
python3 tools/build.py --full       # สร้างเวอร์ชันเต็ม (ครั้งแรกดาวน์โหลดภาพประมาณ 300 MB)
python3 tools/map.py --refresh      # ดึงข้อมูลแผนที่ใหม่ (เพิ่ม --full สำหรับเวอร์ชันเต็ม)
python3 tools/heist.py --refresh    # ดึงแผนที่ Egg Heist ใหม่จาก AniiLog
python3 tools/seo.py                # สร้างหน้าแยกสำหรับค้นหาและ sitemap ใหม่
```

- **ข้อความใหม่ที่ยังไม่ได้แปล:** `build.py` จะเขียนไว้ใน `tools/i18n/missing.json` (`map.py` เขียนใน `missing_map.json`) ให้ใส่คำแปลแล้วเพิ่มลงใน `tools/i18n/th.json` จากนั้นรัน `build.py` อีกครั้ง ข้อความที่ยังไม่แปลจะแสดงเป็นภาษาอังกฤษ
- **ข่าวทางการ:** `scrape.py` จะบอกว่ามีประกาศใหม่บน aniimo.com ที่ยังไม่อยู่ใน `news_seen` ของ `tools/manual.json` หรือไม่ (เช็กอย่างเดียวโดยไม่ดึงข้อมูลเกม: `python3 tools/scrape.py --check`) สรุปข่าวลงใน `content.js` แล้วเพิ่ม id ลงใน `news_seen`
- **ภาษาอังกฤษ:** เปิดเว็บเป็นภาษาอังกฤษ แล้วรัน `window.__i18nMissing()` ในคอนโซลเพื่อดูข้อความที่ยังไม่มีคำแปล ใส่ลงใน `tools/i18n/ui_en.json` แล้วรัน `python3 tools/i18n/ui_en.py`
- **โค้ดแลกของ:** แก้ใน `tools/manual.json` (`scrape.py` จะบอกว่ามีโค้ดใหม่หรือโค้ดที่หายไปจาก Game8) แล้วรัน `build.py`
- **Tier List และทีมตัวอย่าง:** อยู่ใน `index.html` (ค้นหา `const T=` และ `const PRESETS=`)

## ขึ้นโฮสต์บน GitHub Pages (เปิดเป็นสาธารณะ)

1. สร้าง repository ใหม่บน GitHub แล้ว push โปรเจกต์นี้ขึ้นไป (branch `main`)
2. ไปที่ Settings → Pages → Source แล้วเลือก **GitHub Actions**
3. workflow ใน `.github/workflows/pages.yml` จะเผยแพร่เวอร์ชันเว็บให้อัตโนมัติทุกครั้งที่ push

บน GitHub Pages เช็กลิสต์สะสมจะบันทึกในเบราว์เซอร์ของแต่ละคน ส่วนใน Claude Artifact จะบันทึกในบัญชี Claude ของผู้ใช้

## เครดิตและลิขสิทธิ์

ค่าสถานะ สกิล Trait คำอธิบาย ไอเท็ม ตารางธาตุ ชื่อไทย คำแปลไทยทางการ ภาพ Aniimo และร่าง (ภาพสมุดวิจัยในเกม) และไอคอน มาจากข้อมูลในเกม (`gamedata/`) โมเดล 3D และภาพร่างเปล่งประกายทำเองจากไฟล์เกม (`tools/model/`) แผนที่ อีเวนต์ บอส แหล่งไอเท็ม และข้อมูลของ Aniimo ที่ยังไม่อยู่ในไฟล์เกม ยังมาจาก [AniiDex](https://aniidex.com/) ส่วนโค้ดแลกของและ Tier List มาจาก [Game8](https://game8.co/games/Aniimo) ชื่อและภาพ Aniimo เป็นลิขสิทธิ์ของผู้พัฒนาเกม ถ้าจะเผยแพร่สาธารณะควรคำนึงเรื่องนี้ และให้เครดิตแหล่งที่มา

คำแปลภาษาไทยและข้อมูลต่อไปนี้จัดทำขึ้นเองเป็นแนวทาง ไม่ใช่ข้อมูลทางการ: คะแนนทีม ทีมตัวอย่าง และตัวแนะนำสำหรับสู้บอส
